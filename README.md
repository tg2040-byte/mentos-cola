# 🍬 メントスコーラ「投げ込め！」タイムアタック

PCとスマホを連携させた、メントスコーラをテーマにした投球タイムアタックゲームです。

- **PC（表示機）**：大きな画面にコーラのグラスを表示。グラスの位置・距離は難易度によって変わる。名前を入力してスタートすると、命中するまでのタイムを計測する
- **スマホ（投球機）**：野球のボールを投げるように腕を振ると、その"投げ"をモーションセンサーで検知してメントスを1個投下する。外れても自動で次の1投を待機するので、PC側を操作し直さずに何度でも連続で挑戦できる
- スイングの**強さ**で飛距離、**左右の振り方**で着弾位置が変わり、狙い通りグラスに入れば炭酸が噴き出る演出とともにタイムが確定する
- 挑戦者の記録はサーバー側に保存され、難易度ごとのランキングとしてPC画面に残り続ける（同級生・家族と記録を競える）

PCとスマホをWebSocketでリアルタイムに繋ぎ、スマホの加速度センサー（DeviceMotion API）と振動（Vibration API）、PC側のCanvasアニメーションを組み合わせて実装しています。

## 動かし方

WebSocketを使った自前サーバー構成なので、StackBlitzやCodePen、Netlify Drop、GitHub Pagesのような
**静的ファイルだけをホスティングするサービスでは動きません**（サーバープロセスを動かし続けられないため）。
そのため、**方法A（Renderに無料デプロイ）** を推奨します。PCでサーバーを起動しっぱなしにする必要がなくなり、
HTTPS配信になるのでiPhoneのモーションセンサー許可の問題も解決します。

### 方法A：Renderに無料デプロイする（推奨・一度セットアップすればずっと使える）

1. **GitHubにコードを置く**
   - GitHubアカウントがない場合は [github.com](https://github.com) で作成
   - 新しいリポジトリを作成し、このフォルダ（`mentos-cola-game/`）の中身をアップロードする
     - Gitに慣れていない場合は、リポジトリ作成画面の「uploading an existing file」からドラッグ&ドロップでもOK（`node_modules`フォルダはアップロード不要）
2. **Renderにサインアップする**
   - [render.com](https://render.com) にGitHubアカウントでサインアップ
3. **Web Serviceを作成する**
   - ダッシュボードで「New +」→「Web Service」を選択
   - 先ほどのGitHubリポジトリを選択して接続
   - 設定はだいたい自動検出されますが、念のため確認：
     - **Build Command**: `npm install`
     - **Start Command**: `npm start`
     - **Instance Type**: Free
   - 「Create Web Service」をクリック
4. **デプロイ完了を待つ**（数分）
   - `https://<サービス名>.onrender.com` のようなURLが発行される
   - このURLは、Renderのダッシュボードでそのサービスを開いたとき、**サービス名のすぐ下**に表示されています（コピーボタン付き）
5. **PCとスマホでアクセスする**
   - PC: `https://<サービス名>.onrender.com/display.html`
   - スマホ: `https://<サービス名>.onrender.com/controller.html`
   - Wi-Fiが違っても、お互いインターネットに繋がっていればOK（同じWi-Fiである必要はありません）
   - **PCのIPアドレスを調べる必要はありません**（それが必要になるのは下の方法Bだけです）

> ⚠️ Render無料プランは一定時間アクセスがないとスリープします。しばらく放置した後に開くと、
> 最初のアクセスだけ起動に30秒〜1分ほどかかることがあります。撮影直前に一度PCでアクセスして
> 起こしておくとスムーズです。

> 💡 Renderの「Logs」タブに `メントスコーラゲーム サーバー起動 (port ...)` が出ていれば起動成功です。
> そのすぐ下に表示されるURLをPC・スマホで開いてください（`localhost` ではなく `https://〜.onrender.com` の方です）。

### 方法B：PC上でローカル起動する（動作確認・練習用）

素早く手元で試したいときはこちらでもOKです。

```bash
cd mentos-cola-game
npm install     # 初回のみ（ws パッケージをインストール）
npm start        # または: node server.js
```

`http://<このPCのIP>:8787/` が表示されればOKです。PCのIPアドレスは以下で確認できます。

```bash
# Mac
ipconfig getifaddr en0
# Windows (PowerShell)
ipconfig
```

- PC: `http://localhost:8787/display.html`
- スマホ（**PCと同じWi-Fiに接続**）: `http://<PCのIPアドレス>:8787/controller.html`

> ⚠️ この方法はHTTPではないので、iPhoneのSafariでモーションセンサーの許可が下りないことがあります。
> iPhoneを使う場合は方法A（Render）を使うのが確実です。

## 遊び方

1. PC画面で名前を入力し、難易度（かんたん／ふつう／むずかしい）を選んで「スタート」を押す
2. カウントダウンの後、スマホ側に「今だ！投げろ！」と表示されたらタイマー開始。実際に腕を振ってスマホを投げるような動作をする（もちろん投げずに、振るだけでOK）
3. 振りを検知すると、PC画面上でメントスが放物線を描いて飛んでいく
4. コーラのグラスに命中すると炭酸が噴き出る演出とともにタイムが確定。外れた場合は水しぶきの演出が出た後、スマホ側が0.5秒ほどで自動的に次の1投の待機に戻る（PC側を操作し直す必要はない）
5. 命中するまで3の手順を繰り返し、命中した時点の経過時間と投球数が記録される。記録は自動でサーバーに送られ、難易度ごとのランキングにその場で反映される
6. PC側の「👉 次の挑戦者へ」で新しい合言葉（ルームコード）が発行されるので、次の人はスマホでその番号を入力して参加する

**難易度による違い**
| 難易度 | 距離 | 位置 | グラスの大きさ（命中判定半径） |
|---|---|---|---|
| かんたん | 近い | ほぼ中央 | 大きい（110px） |
| ふつう | 中距離 | やや右寄り | 中くらい（78px） |
| むずかしい | 遠い | 左寄り | 小さい（50px） |

各ラウンドで多少ランダムに位置がずれるので、同じ難易度でも毎回微妙に狙いが変わります。実際に試した感触では「むずかしい」の距離感の方がスイングの力加減を合わせやすい、という声もあったので、まずは「むずかしい」から試してみるのもおすすめです。

## 使っている技術

- **DeviceMotion API**（`devicemotion`イベント）— スマホの「投げる」動作（スイングの強さ・左右方向）を検知。ジャーク（加速度の急な変化）でスイング開始を検出し、その後の観測ウィンドウ内での加速度の最大値をピークとして採用することで、振り終わりの減速動作を誤検知しないようにしている
- **Vibration API**（`navigator.vibrate()`）— 投球を検知した瞬間の触覚フィードバック
- **WebSocket**（`ws`パッケージ）— PCとスマホをルームコードでペアリングし、投球データ・判定結果・ランキングをリアルタイムに中継。命中タイムはPC側の計測を正としてスマホに送り返すことで、両者の表示タイムがズレないようにしている
- **Canvas 2D** によるパーティクルアニメーション — コーラが噴き出る演出
- サーバー側メモリ上に保持するランキングデータ — 挑戦者ごとの名前・タイム・難易度を保存し、全クライアントにブロードキャストして常に最新のランキングを表示
- Node.js の `http` モジュールによる自前の静的ファイル配信（Express等は未使用）

## 調整パラメータ（実機に合わせてチューニング）

実際の投げ方の強さはスマホの機種やセンサー感度によって差が出ます。うまく反応しない・的に届かない場合は、以下を調整してください。

`public/controller.html`
- `THROW_THRESHOLD`（デフォルト14）: この値を超える急な加速度変化を「投げ始め」と判定する。反応しすぎる場合は上げる、反応しない場合は下げる
- `CAPTURE_WINDOW_MS`（デフォルト160ms）: 投げ始めを検知してから、実際のピークの強さ・方向を確定するまでの観測時間
- `REARM_DELAY_MS`（デフォルト500ms）: 外れた後、次の1投の待機を再開するまでの間隔（振り終わりの余韻を無視するため）

`public/display.html`
- `POWER_FULL`（デフォルト55）: このスイングパワーで最大飛距離に到達する。実機のパワー値の目安を見ながら調整
- `DIR_FULL`（デフォルト18）: この左右加速度で画面端まで届く目安
- `DIFFICULTIES` 内の `distanceRatio` / `offsetRatio` / `hitRadius`: 各難易度の的の位置・大きさ。現在は「かんたん」でも意外と難しいという声を反映して、初期値より的を大きめ（110/78/50px）にしてあるので、さらに難易度を下げたい場合はここを増やす

コツ：一度実機で投げてみて、スマホ画面に出る「スイングパワー」の実測値を見ながら`POWER_FULL`を合わせるとスムーズです。
